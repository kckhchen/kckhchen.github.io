My Research

MSc Dissertation・University of Warwick

Probabilistic Weather Forecasting

My MSc dissertation "Probabilistic Weather Forecasting with Recursive Algorithms and Vine Copulas ", under the supervision of Dr. Ritabrata Dutta, explores the possibility of utilizing copulas to produce probabilistic forecasts on weather data. It also makes use of a Quasi-Bayesian recursive density estimation algorithm to allow for quick updates of estimates when new data arrives, enabling "online" forecasts where every new observation can be used to refine subsequent predictions without the need to re-train the model.

Open-Source Project

Obsidian-2-Jekyll

Regex-Based Markdown-to-DSL Content Conversion Tool

Built with Python, this is a regex-based tool that converts your Obsidian-styled Markdown syntax to Jekyll-flavored Liquid tags. Obsidian has many handy syntax elements like Wikilinks, embedded images, callouts, etc., which are useful until you wish to publish your posts online. This tools swaps all those elements into Jekyll's DSL Liquid tags so that you can write in your flow freely, and let the tool converts them into perfectly compatible Jekyll posts.

Better yet, this tool syncs your vault with your Jekyll site, so that you can easily upload/delete a post just in your vault, and the tool will organize your Jekyll post/img folder just the way you wish.

Python Jekyll Obsidian
Open-Source Project・Machine Learning

zh-TW NLP Product Categorizer

NLP Product Categorizer for zh-TW E-Commerce Context

This is a lightweight yet powerful NLP training framework that can produce models that categorize products automatically. It utilizes 2 different TF-IDF vectorizers and a SVC/MNB classifier to build a pipeline that is tailored specifically to tackle zh-TW e-commerce datasets, where product names can be messy (a mix of English/numeric/Chinese characters, keyword stacking, etc.).

It also comes with a containerized, production-ready backend API built using FastAPI and Docker, so that a model can be used to predict and solve real-world business problems upon training.
